⌥ Option shortcuts on Mac

Window controls affect desktop Aura. During Chrome sync, session controls apply to the Chrome session capturing audio. Enable Aura in Privacy & Security → Accessibility for shortcuts while another app is focused.

📸 Multi-Screenshot Analysis

You can capture multiple screenshots with Option+S to build a queue, then process them all at once with Option+A. This is highly recommended for complex multi-part coding questions.

⚡ Speed Strategy

If your primary AI model is lagging, use Option+E to immediately trigger Auto-Select. Aura will switch you to the fastest healthy provider available.
